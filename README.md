\# God's Time Travel Service: Booking Landing Page



\*\*Live site:\*\* https://gods-time-travel.vercel.app



A mobile-friendly landing page for a student shuttle service. Customers pick a route, see the fare calculated automatically, and send their booking details straight to WhatsApp.



\## Features

\- Route cards with prices

\- Automatic fare calculation

\- One-tap WhatsApp booking with the details pre-filled

\- Responsive layout for phones



\## Built with

\- HTML, CSS, JavaScript

\- Deployed on Vercel
